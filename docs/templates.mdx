---
title: "Templates"
description: "Start with Rust APIs, TanStack static frontends, or both."
---

Use templates when you want Tovuk to create the project shape.

## Rust API

```sh
npx tovuk init api --template rust-worker
npx tovuk doctor
npx tovuk preview
```

## TanStack Static Frontend

```sh
npx tovuk init web --template tanstack-static-frontend
bun install
npx tovuk doctor
npx tovuk preview
```

## Worker Static

```sh
npx tovuk init hello-service --template worker-static-rust-tanstack
cd hello-service/web && bun install && cd ..
npx tovuk doctor
npx tovuk deploy --wait --json
```

The worker-static template creates `api/`, `web/`, and one root `tovuk.toml`.
The Rust worker owns dynamic server behavior. The TanStack frontend builds to
static files and calls same-origin `/api`.
