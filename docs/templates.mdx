Use templates when you want Tovuk to create the project shape.

## Choose a template

<Tabs>
  <Tab title="Rust API" icon="server">
    Start with a Rust worker API when the service only needs backend routes.

    ```sh
    tovuk new api --template rust-worker
    cd api
    tovuk check --json
    tovuk account show --json
    tovuk deploy --dry-run --json
    tovuk deploy --wait --json
    tovuk service show <service> --json
    tovuk service status <service> --json
    ```
  </Tab>

  <Tab title="TanStack" icon="monitor">
    Start with a TanStack static frontend when the app builds to static files.

    ```sh
    tovuk new web --template tanstack-static-frontend
    cd web
    npm install
    tovuk check --json
    tovuk account show --json
    tovuk deploy --dry-run --json
    tovuk deploy --wait --json
    tovuk service show <service> --json
    tovuk service status <service> --json
    ```
  </Tab>

  <Tab title="Next" icon="panel-top">
    Start with a static Next.js export when the app only needs browser-rendered
    pages.

    ```sh
    tovuk new web --template next-static-frontend
    cd web
    npm install
    tovuk check --json
    tovuk account show --json
    tovuk deploy --dry-run --json
    tovuk deploy --wait --json
    tovuk service show <service> --json
    tovuk service status <service> --json
    ```
  </Tab>

  <Tab title="Full" icon="layers">
    Start with a Rust worker and TanStack static frontend in one service.

    ```sh
    tovuk new hello-service --template fullstack-rust-tanstack
    cd hello-service/web
    npm install
    cd ..
    tovuk check --json
    tovuk account show --json
    tovuk deploy --dry-run --json
    tovuk deploy --wait --json
    tovuk service show <service> --json
    tovuk service status <service> --json
    ```
  </Tab>
</Tabs>

Templates create one root `tovuk.toml` with explicit `[capabilities]`.
The full-stack template also creates `api/` and `web/`. The Rust worker owns
dynamic server behavior. The TanStack frontend builds to static files and calls
same-origin `/api`.
The Next static frontend template sets `output: "export"` in
`next.config.mjs` and uses `[build].output = "out"`. Keep Next API routes,
middleware, SSR handlers, and other server logic out of static frontends; move
that work to a Rust worker.
After deploy, use `tovuk service show <service> --json` before changing
resources, logs, domains, or usage caps. Use
`tovuk service status <service> --json` when you only need the compact live
state.

Without `--template`, `tovuk new` can scaffold a starter `tovuk.toml` from
existing files. That scan is advisory. Deploy behavior is controlled only by
the committed `tovuk.toml`.
