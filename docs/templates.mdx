---
title: "Templates"
description: "Start with Rust APIs, TanStack static frontends, or both."
---

Use templates when you want Tovuk to create the project shape.

## Rust API

```sh
npx tovuk init api --template rust-api
npx tovuk doctor
npx tovuk preview
```

## TanStack Static Frontend

```sh
npx tovuk init web --template tanstack-static-frontend
bun install
npx tovuk doctor
npx tovuk preview
```

## Full Stack

```sh
npx tovuk init my-app --template fullstack-rust-tanstack
cd my-app/web && bun install && cd ..
npx tovuk doctor
npx tovuk deploy --database
```

The full-stack template creates `api/` and `web/`. The Rust API owns dynamic
server behavior, managed Postgres, and CORS. The TanStack frontend builds to
static files and calls the Rust API.
