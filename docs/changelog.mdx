## Week of May 25, 2026

### New

- **Tovuk is the new name for the platform.** The CLI, packages, and Homebrew
  formula now ship under `tovuk`. Install with `npm install -g tovuk`,
  `brew tap tovuk/tovuk https://github.com/tovuk/tovuk && brew install tovuk`,
  `pipx install tovuk`, or `cargo install tovuk`. See [Packages](/reference/packages).
- **One-URL full-stack deploys.** Ship a Rust worker and static frontend
  from one repo with a single root `tovuk.toml`. Run
  `tovuk deploy --wait --json` to get one `*.tovuk.app` URL serving static
  assets at `/` and the worker at `/api/*`. See [Worker](/reference/workers).
- **Project templates and local checks.** Scaffold a Rust API, TanStack static
  frontend, or full-stack project with `tovuk new`, then run
  `tovuk check` to test locally before deploying. See
  [Templates](/templates).
- **Custom domain verification.** Verify and connect custom domains from the
  CLI without leaving your terminal.
- **Agent and deploy inspection commands.** `service show` and `logs` commands
  return structured JSON for service, build, and deploy state so agents can
  debug failed deploys end to end. See the
  [AI agent log and service commands](/agents#log-and-service-commands).
- **Homebrew tap.** Install the CLI on macOS with
  `brew tap tovuk/tovuk https://github.com/tovuk/tovuk && brew install tovuk`.
- **Structured support tickets from the CLI.** Open, list, and resolve tickets
  with `tovuk support` and attach service, build, deploy, and log context for
  faster triage. See the [Support ticket workflow](/agents#support-ticket-workflow).
- **Agent-ready object storage.** Upload, list, download, share, and delete service
  files and media with `tovuk storage` and JSON responses. See
  [Object Storage](/reference/storage).
- **Usage cost estimates.** `tovuk usage --json` now includes
  `billingEstimate.lineItems` so agents can see current-month overage estimates
  before load tests or large uploads.

### Updates

- **Explicit service capabilities.** `tovuk.toml` now uses a required
  `[capabilities]` table so agents can see enabled and disabled service
  surfaces before deploy.
- **Deploy `--wait` mode in SDKs.** The npm, PyPI, and Cargo SDKs now wait for
  builds to finish and stream a final status, with concurrent waits for
  full-stack workspaces.
- **Preflight deploy limits in SDKs.** Plan-limit checks now run before a
  deploy starts, returning a Stripe checkout link via `tovuk billing checkout`
  when an upgrade is needed.
- **Actionable check feedback.** `tovuk check` now returns a concrete
  `agent_instruction` for every failed check so agents can repair issues in
  one workflow. See the [AI agent deploy workflow](/agents#deploy-workflow).
- **Improved workspace check UX.** Faster checks and clearer output for
  full-stack workspaces.
- **Inline CLI flag values.** Flags now accept inline values
  (`--service=service_1`) alongside the existing space-separated form.
- **CLIs are aligned across npm, PyPI, and Cargo.** The same commands,
  flags, and JSON responses are available from every package.

### Fixes

- **Reject unknown CLI flags.** The CLI now errors clearly instead of silently
  ignoring typos.
- **Stable npm signature verification.** Signature checks no longer fail
  intermittently during scoped publishes.
- **Fixed broken agent readiness link in `llms.txt`.**
