Ship Rust workers, static frontends, full-stack services, SQLite data, and
HTTPS endpoints from one command.
Tovuk returns structured feedback so agents can fix issues and deploy again.

```sh
tovuk deploy
```

## Start

- Add a `tovuk.toml` project contract.
- Run `check` before `deploy`.
- Fix any JSON `agent_instruction`.
- Deploy when the checks pass.

```sh
tovuk check
tovuk deploy
```

## Agent prompt

```text
Use Tovuk to deploy this Rust worker for free.
Read https://docs.tovuk.com/llms.txt.
Run `tovuk check`.
Fix any JSON `agent_instruction`.
Run `tovuk deploy`.
```

## Packages

```sh
npm install -g tovuk
brew tap tovuk/tovuk https://github.com/tovuk/tovuk
brew install tovuk
pipx install tovuk
cargo install tovuk
tovuk deploy
```
