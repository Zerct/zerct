Ship a Rust worker, static frontend, SQLite data, and an HTTPS endpoint from
one command.
Tovuk returns structured feedback so agents can fix issues and deploy again.

```sh
tovuk deploy
```

## Start

- Add a `tovuk.toml` project contract.
- Run `check` before `deploy`.
- Fix any JSON `agent_instruction`.
- Deploy when the checks pass.

```sh
tovuk check
tovuk deploy
```

```sh
npm install -g tovuk

brew install tovuk
pipx install tovuk
cargo install tovuk
tovuk deploy
```
