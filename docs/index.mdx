title: "Zerct"
description: "Free Rust backend cloud for agents."
---

Ship a Rust backend, managed Postgres, and an HTTPS endpoint from one command.
Zerct returns structured feedback so agents can fix issues and deploy again.

```sh
npx @zerct/zerct deploy
```

## Start

- Add a `zerct.toml` project contract.
- Run `doctor` before `deploy`.
- Fix any JSON `agent_instruction`.
- Deploy when the checks pass.

```sh
npx @zerct/zerct doctor
npx @zerct/zerct deploy
```
