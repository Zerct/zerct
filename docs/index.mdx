title: "Zerct"
description: "Deploy free Rust backends with managed Postgres and HTTPS endpoints."
---

Zerct deploys free Rust backends with managed Postgres, private logs, and live
HTTPS endpoints.

```sh
npx @zerct/zerct deploy
```

The package checks your project, guides your agent with JSON output, and starts
the deployment from a valid project contract.

## What Zerct expects

- A Rust backend with `Cargo.toml` and `Cargo.lock`
- A `zerct.toml` project contract
- A server that listens on `0.0.0.0:$PORT`
- A health endpoint for deploy verification

## Package surfaces

Use npm for the agent-first flow:

```sh
npx @zerct/zerct deploy
```

Use Homebrew for a persistent developer CLI:

```sh
brew tap Zerct/tap
brew install zerct
zerct deploy
```

Use PyPI from Python environments:

```sh
pipx install zerct
zerct deploy
```

Use crates.io from Rust environments:

```sh
cargo install zerct
zerct deploy
```
