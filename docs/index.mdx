Use public-data scraper APIs, stored Results, Rust services, SQLite data, and
HTTPS endpoints from one command line.
Tovuk returns structured feedback so agents can fix issues and deploy again.

```sh
tovuk deploy
```

## Start

- Add a `tovuk.toml` project contract.
- Run `tovuk check --json` before `tovuk deploy --dry-run --json`.
- Fix any JSON `agent_instruction`.
- Confirm account setup with `tovuk account show --json`.
- Review dry-run output before `tovuk deploy --wait --json`, then capture the
  Service snapshot with `tovuk service show <service> --json`.

```sh
tovuk check --json
tovuk account show --json
tovuk deploy --dry-run --json
tovuk deploy --wait --json
tovuk service show <service> --json
tovuk service status <service> --json
```

## Packages

Choose one package channel. This example uses npm; see
[Packages](/reference/packages) for Homebrew, PyPI, and Cargo.

```sh
npm install -g tovuk
tovuk --version
tovuk --help
tovuk check --json
tovuk account show --json
tovuk deploy --dry-run --json
tovuk deploy --wait --json
tovuk service show <service> --json
tovuk service status <service> --json
```
