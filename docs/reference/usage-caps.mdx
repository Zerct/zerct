---
title: "Usage Caps"
description: "Hard usage stops for predictable Tovuk spend."
---

Usage Caps stop activity at a configured meter threshold. Agents should set caps
before load tests, media uploads, queue fan-out, and paid usage.

## Dashboard

The dashboard Usage view is available at `https://tovuk.com/account/usage` or
`https://tovuk.com/<handle>/usage`. It includes the same hard-cap action as
`tovuk limits set` and the same removal action as `tovuk limits delete`, backed
by the same API routes and rate limits as the CLI. It also opens the same
hosted checkout flow as `tovuk billing checkout --json` for upgrades and paid
overages.

## Agent commands

```sh
tovuk usage --json
tovuk limits set worker_requests --period day --value 100000 --json
tovuk limits set worker_cpu_ms --period day --value 1000000 --json
tovuk limits set object_storage_egress_bytes --period month --value 1000000000000 --json
tovuk limits delete worker_requests --period day --json
```

## API

- `GET /v1/usage`
- `PUT /v1/usage/caps/{metric}`
- `DELETE /v1/usage/caps/{metric}/{period}`

## Agent loop

1. Run `tovuk pricing --json` and read `products[].meter_details`.
2. Run `tovuk deploy --dry-run --json` and read `meterPlan`.
3. Set caps for every enabled capability before high traffic.
4. Run `tovuk usage --json` during tests.
5. If a limit blocks work, run `tovuk billing checkout --json` and show the
   hosted URL to the human.
