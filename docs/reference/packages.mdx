## npm

```sh
npx @zerct/zerct deploy
```

`@zerct/zerct` is the live npm package. The unscoped `zerct` package is the
company package target.

## Homebrew

```sh
brew tap Zerct/tap
brew install zerct
zerct deploy
```

## PyPI

```sh
pipx install zerct
zerct deploy
```

## crates.io

```sh
cargo install zerct
zerct deploy
```
