## npm

```sh
npx @zerct/zerct deploy
```

`@zerct/zerct` is the live npm package. The unscoped `zerct` package is the
company package target.

All official package CLIs expose the same agent commands for login, doctor,
preview, deploy, wait, capabilities, account usage, apps, deploys, builds,
logs, env, domains, and billing.

The agent repair loop is the same on every package surface:

```sh
zerct doctor --json
zerct deploy --wait --json
zerct logs --build job_1 --json
```

Fix `agent_instruction` first. If a build fails, fix the first actionable log
line, rerun doctor, then redeploy.

## Homebrew

```sh
brew tap Zerct/tap
brew install zerct
zerct deploy
```

## PyPI

```sh
pipx install zerct
zerct deploy --wait
zerct logs --build job_1 --json
zerct domains verify --app app_1 api.example.com
```

## crates.io

```sh
cargo install zerct
zerct deploy --wait
zerct logs --deploy deploy_1 --json
zerct billing portal
```
