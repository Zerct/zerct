## npm

```sh
npx @zerct/zerct deploy
```

`@zerct/zerct` is the live npm package and the source of truth for the PyPI,
Cargo, and Homebrew wrappers.

All official package CLIs expose the same agent commands for login, doctor,
preview, deploy, wait, capabilities, account usage, apps, deploys, builds,
logs, env, domains, billing, and support.

The agent repair loop is the same on every package surface:

```sh
zerct doctor --json
zerct deploy --wait --json
zerct logs --build job_1 --json
zerct billing checkout --json
zerct support create "Deploy failed" "Agent retried deploy after doctor." --app app_1 --build job_1 --deploy deploy_1 --failing-command "zerct deploy --wait --json" --first-log-line "cargo check failed in src/main.rs" --json
zerct support resolve ticket_0123456789abcdef0123 --json
```

Fix `agent_instruction` first. If a build fails, fix the first actionable log
line, rerun doctor, then redeploy.

## Homebrew

```sh
brew tap Zerct/zerct https://github.com/Zerct/zerct
brew install zerct
zerct deploy
```

## PyPI

```sh

zerct deploy --wait
zerct logs --build job_1 --json
zerct domains verify --app app_1 api.example.com
```
