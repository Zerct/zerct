## npm

```sh
npx @zerct/zerct deploy
```

The target unscoped package is `zerct`. Until npm approves that name,
`@zerct/zerct` is the public npm package.

## Homebrew

```sh
brew tap Zerct/tap
brew install zerct
```

## PyPI

```sh
pipx install zerct
zerct deploy
```

## crates.io

```sh
cargo install zerct
zerct deploy
```
